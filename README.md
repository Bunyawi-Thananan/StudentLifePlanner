# Student Life Planner

แอป Android สำหรับช่วยนักศึกษาจัดการชีวิตการเรียน ทั้งรายวิชา ตารางเรียน การบ้าน การสอบ และโน้ต ไว้ในที่เดียว

> โปรเจกต์นี้พัฒนาเป็นงานกลุ่ม (3 คน)

## ฟีเจอร์

- **สมัครสมาชิก / เข้าสู่ระบบ** — แต่ละบัญชีเห็นเฉพาะข้อมูลของตัวเอง และระบบจำการล็อกอินไว้
- **หน้าแรก (Home)** — สรุปการบ้านที่ยังไม่เสร็จและการสอบที่กำลังจะมาถึง พร้อมปุ่มลัดไปทุกเมนู
- **รายวิชา (Courses)** — เพิ่ม/แก้ไข/ลบวิชา ระบุรหัสวิชา ชื่อวิชา อาจารย์ หน่วยกิต ภาคเรียน ปี และสีประจำวิชา
- **ตารางเรียน (Schedule)** — บันทึกคาบเรียนของแต่ละวิชา วัน เวลาเริ่ม–เลิก ห้อง อาคาร และประเภทคาบ
- **การบ้าน (Assignments)** — บันทึกงาน กำหนดส่ง ระดับความสำคัญ ติ๊กว่าทำเสร็จแล้ว และกรองดูเฉพาะงานที่ยังค้างได้
- **การสอบ (Exams)** — บันทึกวันสอบ เวลา ห้อง ประเภทการสอบ คะแนนเต็ม และกรอกคะแนนที่ได้หลังสอบ
- **โน้ต (Notes)** — จดโน้ตแยกตามวิชา ใส่แท็ก ค้นหา และกดรายการโปรด
- **โปรไฟล์ (Profile)** — ดูข้อมูลบัญชีและออกจากระบบ

ข้อมูลทั้งหมดเก็บไว้ในเครื่อง (ฐานข้อมูล Room) ไม่ต้องใช้อินเทอร์เน็ต

## เทคโนโลยีที่ใช้

- Kotlin
- Jetpack Compose + Material 3
- Navigation Compose
- Room Database
- ViewModel + Kotlin Coroutines / Flow

## ความต้องการของระบบ

- Android Studio เวอร์ชันล่าสุด (รองรับ Android Gradle Plugin 8.13)
- JDK 17 (มากับ Android Studio อยู่แล้ว)
- มือถือหรือ Emulator ที่ใช้ **Android 7.0 (API 24) ขึ้นไป**

## วิธีติดตั้ง

### 1. ดาวน์โหลดโปรเจกต์

ใช้ Git:

```bash
git clone https://github.com/Bunyawi-Thananan/StudentLifePlanner.git
```

หรือกดปุ่ม **Code → Download ZIP** บนหน้า GitHub แล้วแตกไฟล์

### 2. เปิดใน Android Studio

1. เปิด Android Studio แล้วเลือก **File → Open**
2. เลือกโฟลเดอร์ `StudentLifePlanner` ที่ดาวน์โหลดมา
3. รอให้ Gradle Sync เสร็จ (ครั้งแรกอาจใช้เวลาสักครู่เพราะต้องดาวน์โหลด library)

### 3. รันแอป

**บน Emulator**
1. ไปที่ **Tools → Device Manager** แล้วสร้างอุปกรณ์จำลอง (API 24 ขึ้นไป)
2. เลือกอุปกรณ์ที่แถบด้านบน แล้วกดปุ่ม **Run ▶** (หรือ `Shift + F10`)

**บนมือถือจริง**
1. เปิด **ตัวเลือกสำหรับนักพัฒนา (Developer options)** และเปิด **USB debugging** ในมือถือ
2. ต่อมือถือเข้ากับคอมพิวเตอร์ด้วยสาย USB แล้วกดอนุญาตบนมือถือ
3. เลือกมือถือที่แถบด้านบนของ Android Studio แล้วกด **Run ▶**

**สร้างไฟล์ APK**
- ไปที่ **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
- ไฟล์จะอยู่ที่ `app/build/outputs/apk/debug/app-debug.apk` นำไปติดตั้งบนมือถือ Android ได้เลย

## วิธีใช้งาน

### เริ่มต้นใช้งาน
1. เปิดแอปครั้งแรก กด **Sign Up** เพื่อสมัครสมาชิก กรอกชื่อ-นามสกุล ชื่อผู้ใช้ อีเมล รหัสผ่าน (และรหัสนักศึกษาถ้ามี)
2. กลับมาหน้า **Login** แล้วเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน
3. แอปจะเข้าสู่ **หน้าแรก** ซึ่งมีปุ่มไปยังทุกเมนู

### ขั้นตอนแนะนำ
> **เพิ่มรายวิชาก่อนเสมอ** เพราะตารางเรียน การบ้าน การสอบ และโน้ต ต้องเลือกวิชาที่ผูกไว้

1. **Courses** — กดปุ่ม **+** เพื่อเพิ่มวิชาที่ลงเรียน
2. **Schedule** — กด **+** แล้วเลือกวิชา วันในสัปดาห์ เวลาเริ่ม–เลิก และห้องเรียน
3. **Assignments** — กด **+** เพื่อเพิ่มการบ้าน
   - กรอกวันที่ในรูปแบบ `YYYY-MM-DD` (เช่น `2024-12-31`) และเวลาแบบ `HH:MM` (เช่น `23:59`)
   - ติ๊กช่อง ✓ เมื่อทำเสร็จ
   - กดไอคอนตัวกรองที่มุมขวาบนเพื่อดูเฉพาะงานที่ยังไม่เสร็จ
4. **Exams** — กด **+** เพื่อเพิ่มการสอบ หลังสอบเสร็จสามารถติ๊กว่าสอบแล้วและกรอกคะแนนที่ได้
5. **Notes** — กด **+** เพื่อจดโน้ต ใส่แท็กคั่นด้วยเครื่องหมายจุลภาค (เช่น `study, important, review`) ใช้ช่องค้นหาด้านบนเพื่อหาโน้ต และกดดาวเพื่อเป็นรายการโปรด

### แก้ไขและลบข้อมูล
- กดไอคอน **ดินสอ (Edit)** บนรายการเพื่อแก้ไข
- กดไอคอน **ถังขยะ (Delete)** เพื่อลบ ระบบจะถามยืนยันก่อนลบ

### ออกจากระบบ
ไปที่ **Profile** แล้วกด **Logout**

```
├── data/

│   ├── model/                # ตารางข้อมูล (User, Course, Schedule, Assignment, Exam, Note)
│   └── repository/           # Repository
├── ui/
│   ├── navigation/           # การเปลี่ยนหน้า
│   ├── screen/               # หน้าจอทั้งหมด
│   ├── theme/                # สีและฟอนต์
│   └── viewmodel/            # ViewModel
├── utils/                    # ฟังก์ชันช่วยเหลือ (วันที่, ค่าคงที่, การจำการล็อกอิน)
└── MainActivity.kt
```
